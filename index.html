    How editing works
    
        
      
          
    1. This page is static and can't save anything itself, so the form builds a GitHub issue with the trade as JSON (label trade).
      2. 
          
    2. You tap Submit new issue on GitHub (you need to be signed in as AT4Engineer).
      3. 
          
    3. The Apply trade GitHub Action checks it. If it's valid it updates data/holdings.json, records it in Transactions, recalculates the dashboard, comments a before/after summary and closes the issue.
      4. 
          
    4. If something is wrong (for example selling more than you hold) it comments the reason, closes the issue and changes nothing.
      5. 
        
    
        
    Issues in this repository are public, like the rest of the dashboard. Issues opened by anyone else are ignored.
